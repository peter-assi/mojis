# Repository instructions

- Store emoji images in `emojis/`, named after their Slack emoji name with the original file extension.
- Every emoji added in the future must also be added to the `README.md` gallery in the same change, with a rendered image preview and its `:emoji_name:`.
- Keep the README gallery alphabetically sorted and its emoji count up to date.
- Preserve original image files, including animated GIFs; do not replace animations with still images.
- When renaming or removing an emoji, update its README entry in the same change. Verify that every gallery image path exists and every emoji file appears in the gallery.
